## ฝากพิจารณาด้วยท่านประธาน

-แก้ของโปรเจคในไฟล์หลัก ไม่ได้แก้ใน โฟลเดอร์ webboard เพราะมันซ้ำกัน
-แก้ bug ผู้ใช้ลบ post ตัวเองไม่ได้ รวมถึง admin ก็ลบไม่ได้ (ไม่รู้ว่าเจอ bug นี้หรือป่าว) แต่แก้ให้มันรันได้แบบ sure sure ดีกว่า
-เพิ่มระบบ weak password ไม่ให้ตั้งรหัสผ่านโง่ๆได้ ตอนเทสมันตั้ง 1234567891234 แล้วผ่าน แต่สำหรับ admin ยังไม่ได้แก้ ยังตั้งรหัสผ่านโง่ๆผ่านได้เหมือนเดิม เดี๋ยวยุ่งยาก 
-อัพเกรดความปลอดภัยเรื่องของ role ใน database ของ admin เพราะตอนแรกถ้าไปเปลี่ยน role ในฐานข้อมูลทันทีขณะล็อกอิน มันจะไม่อัพเดท แก้ให้มันอ่านจาก db โดยตรง ณ ขณะนั้น
-test แล้วผ่านหมด
-อ่าน security-test-result ได้ หลักๆคือ มันบอกว่าทุกอย่างผ่านหมด แต่กังวลเรื่องของการขโมย .env แล้วเอาไปบอกคนอื่น มันจะ hack งานได้ แล้วก็ที่เหลืออัพเกรดตามนี้หมดละ
